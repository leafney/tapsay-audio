安装：双击 TapSayAudio-2ch-@VERSION@.pkg。
卸载：双击“卸载 TapSay Audio.app”。
卸载完成：工具确认驱动文件、安装状态、收据及系统设备均已移除，并已清理可安全确认归属的旧版安装材料。
卸载待重启生效：文件已清理，但系统仍保留设备；请保存工作并手动重新启动 Mac。
卸载生效状态待确认：无法核实系统设备；不能视为完全卸载，请重启后复查。
卸载未完成：操作失败或仍有文件残留，请保留错误信息以便排查。
工具不会自动重启系统。

支持范围
- macOS 14 及以上。
- 本 DMG 只适用于 Apple Silicon arm64。
- 固定双声道。
- 默认采样率 48 kHz；遥控器源仍为 16 kHz 单声道，驱动不因此限制为 16 kHz。
- 支持 8、16、24、44.1、48、88.2、96、176.4、192、352.8、384、705.6、768 kHz，均为双声道 Float32。

安装行为
- 安装不会主动修改系统默认输入、输出或提示音设备。
- 安装不会删除或替换 MiRemoteV 2ch、BlackHole 2ch 等其他声卡。
- 允许新版覆盖旧版、同版本修复安装和旧版覆盖新版。
- 覆盖期间临时保留当前版本；事务失败时尝试恢复安装前版本。
- 安装成功后自动清理临时旧驱动，不长期保留备份文件。
- 安装已提交后若仅临时清理失败，不会回滚新版本；重新运行新版安装或卸载工具可重试。
- 只有安装失败且自动恢复也失败时，才保留唯一的人工恢复材料。
- 安装和卸载入口是原生程序；无需安装 Python 或 Xcode。
- 安装完成后重新枚举声卡；需要重启时会提示重启后生效，不自动重启。
- 普通用户安装后请在接收软件中选择“TapSay Audio 2ch”。
- 卸载会清理可核验归属本产品的旧版历史材料；未知对象、活动事务和待恢复材料会保留并明确列出。
- 已卸载后如仍有旧版历史材料，可直接再次运行新版卸载工具，无需重新安装声卡。
