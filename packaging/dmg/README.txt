TapSay Audio 2ch

许可文件
- GPLv3 完整条款见 GPL-3.0.txt。
- BlackHole 上游来源和第三方许可说明见“第三方许可说明.md”。

安装：双击 TapSayAudio-2ch-0.1.0.pkg。
卸载：双击“卸载 TapSay Audio.app”。

支持范围
- macOS 14 及以上。
- 本 DMG 只适用于 Apple Silicon arm64 或 Intel x86_64 中的一个架构。
- 固定双声道。
- 默认采样率 16 kHz。
- 支持 16、44.1、48 kHz；不公开支持 96 kHz 及以上。

安装行为
- 安装不会主动修改系统默认输入、输出或提示音设备。
- 安装不会删除或替换 MiRemoteV 2ch、BlackHole 2ch 等其他声卡。
- 允许新版覆盖旧版、同版本修复安装和旧版覆盖新版。
- 覆盖前会备份当前版本；事务失败时尝试恢复安装前版本。
- 安装和卸载入口是原生程序；无需安装 Python 或 Xcode。
- 安装完成后重新枚举声卡；需要重启时会提示重启后生效，不自动重启。
- 普通用户安装后请在接收软件中选择“TapSay Audio 2ch”。

状态说明
- 当前开发包未签名、未公证。
- 只有看到 TapSay Audio 2ch 不等于真实音频链路已验证。
- 各架构真机验收、软件版本和已知问题以正式发布说明为准。
