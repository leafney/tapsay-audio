## 代码处理

- reference 配置的 Box DeviceList 在已获取 Box、容量不足一个对象时，
  返回大小错误，写入零字节且不改变调用者缓冲区；未获取 Box 时仍返回零项。
- reference 名义率变更请求固定向主设备提交，隐藏设备请求也遵守同一规则。
- UID→Box 恢复参考的重复匹配步骤，自有固定 UID 以字符串格式化适配，
  避免因参考的声道格式参数在自有 UID 中未被使用而产生编译警告。
- 保留获批的三类错误修正：OwnedObjects 索引、UID qualifier 大小校验、
  隐藏设备控制列表筛选。产品身份、资源和系统下限沿用原批准边界。
- legacy 的零容量列表与采样率请求目标行为保持既有合同。

## 源码差异复核

来自已冻结的无线麦补丁。差异按以下类别人工审阅：

1. 产品宏、固定 UID/名称字符串、制造商、移除伪序列号和未采用图标。
2. 已批准的三类错误修正。
3. legacy/reference 分支；reference 展开后恢复双设备枚举、虚拟 Box、
   48 kHz 初始率及完整率表。
4. 等价表达：两个设备条件抽为辅助函数，UID 返回分支简化，
   数量计算表达式以及删除未使用的时间戳局部变量。

IO 读写、主机时钟计算、采样率应用和零时间戳运行路径没有新增优化。
归一化完整源码差异随 `reference-audit.json` 保存；这份文本差异包含 identity
和兼容分支，不将差异行数解释成运行差异数量或自动语义等价证明。
