# Intel 安装包命名讨论

## 原始需求

将生成的 Intel 安装包文件名中的 `x86_64` 改为 `amd64`，与 `arm64` 命名保持一致。

## 问答

**问：**是否同时修改手动构建产物和 Release 中的安装包名称？

**答：**用户确认两处同时修改。

## 共同理解

- 用户可见的 Intel 安装包名称使用 `amd64`；Apple Silicon 继续使用 `arm64`。
- 编译、运行时架构识别和 Mach-O 校验继续使用 macOS 原生架构名 `x86_64`；`amd64` 只是文件命名标签。
- 认证与未认证命名规则、签名验证及最低系统版本维持原有行为。
